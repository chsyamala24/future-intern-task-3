# Task 3 - Local Business Website & Live Pitch Project

## Project Overview
This project is a professional website developed for a local restaurant business using HTML, CSS, and JavaScript. The website provides information about the restaurant, its menu, services, and contact details through a clean and responsive design.

## Features
- Responsive and mobile-friendly design
- Attractive homepage
- Menu section
- About Us section
- Contact form
- Table booking button
- Easy navigation

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Objective
The objective of this project is to create a modern website for a local business and improve its online presence while applying front-end web development skills.

## Project Outcome
- Developed a responsive business website
- Improved UI/UX design skills
- Gained experience in real-world web development projects
